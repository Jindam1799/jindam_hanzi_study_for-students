# 진담 한자어 놀이터

진담중국어가 매주 올리는 **교과서 속 한자어** 웹게임입니다.
주소: https://jindam1799.github.io/jindam_hanzi_study_for-students/

## 들어 있는 놀이 (6가지)

| 놀이 | 하는 일 | 덩어리훈련과의 연결 |
|---|---|---|
| 한자어 카드 | 낱말을 글자별 뜻(훈·음)으로 쪼개 보고, 중국어 소리 듣기 | 부담 없이 보고 듣기 |
| 따라 쓰기 | 한 글자를 **3번씩** 획순 따라 쓰기 (1·2번째는 회색 글자, 3번째는 스스로) | 손으로 익히기 |
| 카드 짝 맞추기 | 한자 ↔ 우리말 카드 6쌍 뒤집기 | 인지·연결 |
| 같은 글자 찾기 | 生 같은 글자가 들어간 낱말 모두 찾기 | 한 글자로 낱말 넓히기 |
| 뜻 조립 퀴즈 | "빛 광 + 합할 합 + 이룰 성" → 광합성 / 한자 보고 뜻 고르기 | 이해 |
| 중국어 소리 퀴즈 | 중국어 소리를 듣고 우리말 낱말 고르기 | 한자어 → 중국어 소리 |

틀린 문제는 **두 문제 뒤에 다시 나오고**, 다 맞혀야 끝납니다. 끝나면 헷갈렸던 낱말을 한 번 더 보여 줍니다.

## 매주 업데이트하는 방법 (파일 2개만)

1. `data/_template.js`를 복사해 `data/week02.js`로 저장하고 내용을 채웁니다.
   - `id`를 `"week02"`, `no`를 `2`로 바꾸기
   - 낱말마다 `hanja`, `hangul`, `subject`, `parts`(글자별 [한자, 훈, 음]), `meaning`은 꼭 넣기
   - `zh`(중국어 간체)·`py`(병음)를 넣으면 소리 퀴즈에도 나옵니다
2. `data/weeks.js` 목록 끝에 `"week02"`를 추가합니다.
3. 같은 파일의 `JINDAM_NEXT`(다음 주 예고: 열리는 날짜, 주제, 힌트 글자)를 그다음 주 내용으로 바꿉니다.
4. (선택) `js/app.js` 맨 위 `APP_VERSION`을 올리면 화면 오른쪽 위 번호로 최신 반영을 확인할 수 있어요.

목록의 **마지막 주차가 첫 화면**에 나오고, 지난 주차는 로비의 「주차 고르기」에서 고를 수 있습니다.
전에 와 본 학생에게는 새 주차가 열렸을 때 「N주차가 열렸어요!」 팝업과 NEW 표시가 뜹니다.
GitHub에 올린 뒤 1~2분, 길게는 10분쯤 지나면 반영됩니다.

## 시작 흐름과 미션

- 인트로(화면을 터치해 주세요) → 📢 모집 안내 팝업 → 「이렇게 놀아요」 팝업 → 로비
- 로비: 안내 띠, 주차 고르기(다음 주차는 잠금 + D-day), 미션 1~6, 다음 주 예고 카드
- 미션을 끝내면 버튼 옆에 빨간 「참 잘했어요」 도장, 6개를 모두 끝내면 큰 「N주차 미션 완료」 도장과 복습 안내 팝업
- 뜻 조립 퀴즈: 보기는 한자, 💡 힌트(우리말 읽기 → 틀린 보기 2개 지우기)
- 카드 짝 맞추기: 처음 3초 카드를 보여 준 뒤 뒤집으며 시작
- 따라 쓰기: 글자마다 획순을 먼저 자동으로 보여 주고 시작
- ⚙️ 설정: 중국어 음성 크기·빠르기·목소리 고르기, 효과음 크기

## 기능 메모

- **항상 Chrome에서 열기**: 카카오톡·네이버·인스타그램 앱 안에서 링크를 열면 Chrome으로 넘깁니다 (`js/inapp.js`).
  Android는 자동으로 넘어가고, iPhone은 Chrome이 설치되어 있으면 Chrome으로, 없으면 안내 띠가 보입니다.
  주소 끝에 `?stay=1`을 붙이면 넘기지 않습니다(테스트용).
- **중국어 음성**: Tingting 음성을 먼저 고르고, 없으면 기기의 다른 중국어(보통화) 음성을 씁니다 (`js/tts.js`).
  맥 Chrome에서 Tingting이 멈춰 소리가 안 나면 2.5초 뒤 다른 중국어 목소리로 자동으로 바꿔 읽습니다. 설정에서 목소리를 직접 고를 수도 있어요.
  문제가 있을 때 개발자 도구 콘솔에서 `[TTS]` 로그나 `window.__ttsLog`를 보면 됩니다.
- **따라 쓰기 획순 자료**: [Hanzi Writer](https://hanziwriter.org) (Make Me a Hanzi 자료, CDN에서 불러옴).
  획순 자료가 없는 글자는 흐린 글자 위에 손으로 따라 그리는 칸으로 바뀌고 "다 썼어요"로 넘어갑니다.
- **확대·스크롤·복사 방지**: 핀치 확대, 두 번 탭 확대, Ctrl+휠, 화면 끌기, 길게 눌러 복사, 우클릭, 복사·붙여넣기를 막습니다.
- **도장 기록**: 놀이를 끝내면 그 기기 브라우저에만 도장이 저장됩니다 (로그인·서버 없음).
- **링크 미리보기 / 아이콘**: `assets/og.png`, `assets/icon-*.png`. 카카오톡은 미리보기를 오래 저장하므로 바꾼 뒤에는
  [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 캐시를 지워 주세요.

```
js/write.js             따라 쓰기
data/weeks.js           ▶ 매주 고치는 목록
data/week01.js          1주차 낱말
data/_template.js       새 주차 틀
assets/                 아이콘, 미리보기 그림
```
